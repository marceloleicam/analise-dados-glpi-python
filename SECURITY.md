# Segurança

## Dados da demonstração

Todos os chamados incluídos neste repositório são fictícios. Nomes de técnicos,
departamentos, categorias e datas foram criados exclusivamente para demonstrar
o funcionamento do projeto.

## Uso com dados reais

- Não publique exportações reais do GLPI no GitHub.
- Remova nomes, e-mails, descrições, anexos e outros dados pessoais.
- Não inclua tokens, senhas, URLs internas ou strings de conexão no código.
- Use variáveis de ambiente ou um gerenciador de segredos para credenciais.
- Restrinja permissões dos arquivos e relatórios gerados.

Falhas de segurança identificadas neste projeto devem ser comunicadas de forma
privada ao autor, sem a publicação de dados sensíveis.
